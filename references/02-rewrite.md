# S1 · 洗稿（原创改写）与事实底稿

这里的「洗稿」指**把材料改写成自己的教学脚本**，不是同义词替换。目标有两个：内容合规可发布，以及每个画面上的字都能回查到出处。

## 红线（进脚本前逐条过）

| 项 | 要求 |
|---|---|
| 身份信息 | 不出现作者名、出品方、机构名、官方品牌背书、价格 / 报价 |
| 案例 | 一律标「教学演示」「虚构样例」；不写成真实客户案例，不出现可识别的个人信息 |
| 效果承诺 | 禁用「保过 / 通过率 / 上岸率 / 效率翻倍 / 彻底替代」等比例或承诺性表述（《广告法》第 24 条）。改用事实陈述：带过多少人、多少卷多少题、做了哪几步 |
| 境外服务 | 保留「用之前先确认你所在地区能不能用」 |
| 数字与专有名词 | 必须能回查到原文的出处 / 页码 / 链接；宁可标「未确认」也不要猜 |
| 术语 | 全片只用一种写法（例：统一「待指定」，不要一处「待解决」一处「待指定」） |
| 图片 | 原文里的教学演示图不直接用，重绘成手绘示意图 |
| 风格 | 口语化但不随便，用具体细节代替情绪词；不用「赋能 / 破局 / 底层逻辑」 |

## 事实底稿 `brief.md`

每集一份，两段式（模板见 `templates/brief.md`）：

```
# <集名> · 事实来源与屏幕文字登记

对应手册：第 X 章 …（原创重写，不出现作者名 / 出品方 / 价格 …）

## 事实来源对照
- 逐条写明结论来自文章哪一部分，含数字、专有名词、操作步骤。

## On-screen text（逐条登记）
- <屏幕上出现的每一个字符串，原样一行>
```

**硬要求**：`index.html` 里出现的每个字符串都在 `On-screen text` 里登记。加了临时文案、改了一个字，必须同步改这里。渲染器的 fact-check 与本 skill 的 `qa.mjs` E6 都会查；漏登记直接拦截。

登记可以从 `index.html` 自动提取一遍再人工过目：

```python
import re
html = open('index.html').read()
zh = [s for s in re.findall(r"'([^']*)'", html) if re.search(r'[\u4e00-\u9fff]', s)]
print('\n'.join('- ' + s for s in dict.fromkeys(zh)))
```

## 旁白 `script.json`

- 一集 8–9 句，约 150–175 秒；`lead_in: 1.2`、`gap: 0.35`、`tail: 1.5`、`bgm: "bright"` 都是顶层字段。
- 开头 1–2 句必须有钩子，别用「大家好今天我们来介绍…」；封面和 BGM 从第 1.2 秒同时起，不浪费前 3 秒。
- **把可锚的对应词埋在句子前 2/3**。后面 `index.html` 的 `W_(id, phrase)` 要靠这些词做逐词点亮；若关键词全挤在句尾，画面前大半段会只有标题（见 `04-render.md` 的 W2）。
- 旁白定稿后立刻跑 TTS；改了旁白就要重新核对所有锚点。

## 自检

- [ ] 全文搜不到作者名 / 机构名 / 品牌 / 价格
- [ ] 没有比例或承诺性表述
- [ ] 案例都标了教学演示
- [ ] 术语一致
- [ ] 每个屏幕字符串都在 `brief.md` 里
- [ ] 每句旁白前半段都有至少一个可作锚点的实词
